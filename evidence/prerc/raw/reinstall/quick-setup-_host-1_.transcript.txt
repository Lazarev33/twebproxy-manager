How to connect Telegram
  1. Open the Link on the device with Telegram, or send it to yourself in Telegram and tap it; the TG link opens Telegram directly.
  2. Telegram should offer to add this proxy; accept it. Nothing else (port, protocol) has to be entered: it is all in the link.
  3. One profile is one secret: give separate users or groups their own profiles, so access can be changed or revoked individually.
  Client support: a Telegram client with WEB Proxy support is required; this manager does not check client versions. Desktop and mobile clients are verified during pre-release testing.
  If it does not connect: open https://<host-1>/ in a browser (the certificate must be valid), then run: twebproxy status <host-1>; details: twebproxy diagnose <host-1>

Next steps
  - Check the state: twebproxy status <host-1>
  - More users or devices: twebproxy profile-add <host-1>
  - Only if connections fail on a restrictive network: Network compatibility / Anti-DPI (advanced); see twebproxy dpi list-methods
