Для hostname нужна DNS-запись A, указывающая на этот сервер. Telegram WEB Proxy работает по HTTPS на порту 443; для автоматических сертификатов нужен ещё порт 80.
Hostname WEB-proxy (без https://): Тип настройки:
  [1] Быстрая (рекомендуется): порты автоматически, профиль «default», новый secret, carrier https
  [2] Расширенная: порты, профиль, secret, carrier и лимиты MTProxy вручную
> 
WEB Proxy использует публичный HTTPS/443 — порт в клиенте не задаётся.

На том же hostname работает обычный сайт. Лучше указать настоящий сайт или приложение; заглушка лишь показывает, что HTTPS работает.
Обычный сайт на hostname:
  [1] Временная страница-заглушка (создаётся автоматически; позже замените настоящим сайтом)
  [2] Мой статический сайт: скопировать каталог с index.html
  [3] Моё веб-приложение на этом сервере (адрес loopback)
> SSL / reverse proxy:
  [1] Caddy — автоматический HTTPS-сертификат (рекомендуется)
  [2] Nginx + Let's Encrypt (автоматическое продление; нужен порт 80)
  [3] Nginx + мой сертификат и ключ
  [4] Вручную: порт 443 уже обслуживает мой веб-сервер (для опытных)
>

Как подключить Telegram
  1. Откройте «Ссылку» на устройстве с Telegram или отправьте её себе в Telegram и нажмите; «Ссылка TG» открывает Telegram напрямую.
  2. Telegram предложит добавить этот прокси — подтвердите. Больше ничего (порт, протокол) вводить не нужно: всё уже есть в ссылке.
  3. Один профиль — один secret: выдавайте разным пользователям или группам отдельные профили, чтобы доступ можно было сменить или отозвать по отдельности.
  Поддержка клиентов: нужен клиент Telegram с поддержкой WEB Proxy; Manager не проверяет версии клиентов. Работа на компьютере и телефоне проверяется на предрелизных испытаниях.
  Если не подключается: откройте https://gamma.example/ в браузере (сертификат должен быть действительным), затем выполните: twebproxy status gamma.example; подробности: twebproxy diagnose gamma.example

Что дальше
  - Проверить состояние: twebproxy status gamma.example
  - Ещё пользователи или устройства: twebproxy profile-add gamma.example
  - Только если подключения не проходят в сети с ограничениями: «Совместимость сети / Anti-DPI (для опытных)»; см. twebproxy dpi list-methods
